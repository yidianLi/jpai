# Stage 4：AI 采购需求理解

## 范围

- `POST /api/procurement/ai-preview` 接收 JSON `{ "request": "..." }`，长度限制 1-2000 字符。
- AI 只提取采购数量与资产类别，不直接生成 SQL、不写入资产主数据。
- 提取结果继续交给 `ProcurementService.preview` 计算闲置可调拨数、采购缺口、预算参考和历史候选型号。

## 运行边界

- AI 配置从系统 AI 配置表读取，支持线上 OpenAI 兼容接口与 Ollama。
- 模型不可用、未启用或返回非 JSON 时，接口使用正则提取数量；无法识别时数量默认为 1，类别为空。
- 采购预览仍是只读建议，不自动创建采购单。

## 验收标准

1. JSON body 调用接口不会因中文或长查询字符串触发参数解析错误。
2. AI 返回有效 JSON 时，响应包含 `ai_used=true`、provider/model 及规则计算结果。
3. AI 不可用时接口仍返回规则预览，且 `ai_used=false`。
4. 前端采购表单在桌面与窄屏可换行，结果摘要不溢出。
