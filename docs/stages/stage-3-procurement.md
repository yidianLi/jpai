# Stage 3：采购建议

## 已实施

- 新增 `POST /api/procurement/preview` 只读预览接口。
- 输入资产类别和需求数量，优先检索闲置资产并计算采购缺口。
- 返回可调拨资产、采购缺口、预算参考和历史候选型号。
- 新增“采购决策分析 → 采购建议”页面。
- 当前预览不自动下单、不修改资产，品牌可靠性结论受 Stage 0 数据质量限制。
- 已增加采购建议单保存、列表和人工确认接口，确认不等于自动下单。
- 采购预测已独立归入“采购决策分析”二级菜单，支持 3/6/12 个月预测周期和重新计算。

## 验收

- 后端编译、路由注册和前端生产构建通过。
- 后端服务重启后健康检查正常。

## 后续扩展

维修和品牌数据补齐后，继续增加审批流、采购单对接和候选型号的时间范围对比。
